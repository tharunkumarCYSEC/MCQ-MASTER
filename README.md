# MCQ Master 

a super simple, messy flask app i built to turn study notes into multiple-choice quizzes. no bloat, just raw code and terminal vibes.

## how to use
1. paste your notes into the text box on the site.
2. click **Make Quiz!**
3. select your answers and check your score.

>  **important:** your notes **must have at least 4 sentences** or the app will complain and tell you to add more text.

## tech stack
* python (flask==3.0.2)
* html / css / vanilla js
* pure panic and caffeine

## how to run it locally
clone the repo and run these commands in your terminal:

```bash
pip install -r requirements.txt
python app.py
