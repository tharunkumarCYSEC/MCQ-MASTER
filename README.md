# MCQ Master 📝✨

It's an MCQ generator in the web!
It's  a basic model finished now and I know it's not much cause I didn't really spend much time, but it's smtg I did in my free time to make studying a bit less painful.

The features it has:
* A clean, distraction-free web interface powered by Tailwind CSS so you can just drop your notes and go.
* A Python Flask backend that handles the heavy lifting of turning raw text blocks into practice questions.
* Built-in automated tests (`_test.py`) just to make sure things actually work under the hood.
* A lightweight setup that you can spin up locally in seconds.
